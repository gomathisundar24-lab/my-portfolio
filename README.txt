MY CINEMATIC PORTFOLIO

FILES
- index.html: website structure
- style.css: layout, colors, responsive design and animations
- script.js: intro animation, scroll reveals and mobile menu
- assets/profile.png: your portrait (About section)
- assets/profile-cutout.png: same portrait with transparent background (dark band section)

HOW TO RUN
1. Extract this ZIP.
2. Open the extracted my-portfolio-cinematic folder in VS Code.
3. If you already have a my-portfolio folder, copy these files into it and allow replacement of index.html/style.css/script.js when asked.
4. Keep the assets folder beside the three code files.
5. In VS Code, install the free "Live Server" extension.
6. Right-click index.html and choose "Open with Live Server".

PERSONALIZE BEFORE PUBLISHING
- Replace "Gomathi Sundar" and other sample text if needed.
- Replace yourmail@example.com with your real contact email.
- Edit the skills and project descriptions to match your actual experience.
- Replace assets/profile.png with your preferred portrait if desired.

NOTES
- The opening intro runs automatically once each time the page is loaded; visitors can skip it.
- Scroll animations start as each section enters view.
- The design uses Google Fonts from the internet; a connection is needed for those fonts.
- No music is included. Browsers commonly block audio autoplay; music should be optional and user-controlled.
